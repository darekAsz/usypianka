## Phase Goal

**As a** parent, **I want to** choose a built-in noise, set a time and start playback, **so that** the sound fades in gently, loops without audible gaps (also with the screen locked) and fades to silence and stops when the time is up.

*(Story assembled from the ROADMAP Phase 1 Goal clauses; the ROADMAP Goal line itself was not rewritten.)*

**This plan's slice:** the rules behind the player screen — which time the parent picked (chips or a validated custom time), what is locked while playing, when Start may be pressed, and what the countdown shows — as a pure, fully tested state model. It runs in parallel with the device spike (plan 01-04) and is rendered by plan 01-06.

```kotlin
// pl.usypianka.ui (PlayerUiState.kt) — no Android imports
enum class TimePreset(val minutes: Int) { M15(15), M30(30), M45(45), M60(60) }
sealed interface DurationChoice { data class Preset(val preset: TimePreset) : DurationChoice; data class Custom(val ms: Long) : DurationChoice }
sealed interface CustomDurationResult {
  data class Accepted(val state: PlayerUiState) : CustomDurationResult
  data object TooShort : CustomDurationResult; data object TooLong : CustomDurationResult
  data object InvalidMinutes : CustomDurationResult; data object InvalidNumber : CustomDurationResult
  data object Locked : CustomDurationResult
}
data class DurationParts(val hours: Int, val minutes: Int)
const val STOP_COOLDOWN_MS = 1_500L
const val EXTEND_STEP_MS = 300_000L
data class PlayerUiState(
  val selectedNoise: Noise = Noise.PINK,
  val duration: DurationChoice = DurationChoice.Preset(TimePreset.M15),
  val volume: Float = VolumeMap.DEFAULT,
  val session: SessionState = SessionState.Idle,
  val startCooldownUntilMs: Long = 0L,
) {
  val durationMs: Long; val isRunning: Boolean; val playingNoise: Noise?
  val selectionEnabled: Boolean; val extendVisible: Boolean; val previewAvailable: Boolean
  fun startEnabled(nowMs: Long): Boolean
  fun remainingMs(nowMs: Long): Long?
}
fun PlayerUiState.selectNoise(noise: Noise): PlayerUiState
fun PlayerUiState.selectPreset(preset: TimePreset): PlayerUiState
fun PlayerUiState.applyCustomDuration(hoursText: String, minutesText: String): CustomDurationResult
fun PlayerUiState.withVolume(position: Float): PlayerUiState
fun PlayerUiState.withSession(session: SessionState): PlayerUiState
fun PlayerUiState.onStopRequested(nowMs: Long): PlayerUiState
fun splitDuration(ms: Long): DurationParts
```
