## Phase Goal

**As a** parent, **I want to** choose a built-in noise, set a time and start playback, **so that** the sound fades in gently, loops without audible gaps (also with the screen locked) and fades to silence and stops when the time is up.

*(Story assembled from the ROADMAP Phase 1 Goal clauses; the ROADMAP Goal line itself was not rewritten.)*

**This plan's slice (UAT gap closure):** the end-of-session fade is heard almost to 0:00 instead of vanishing about 7 s early (G-01-2b), Stop fades audibly for its whole 2.5 s, and the tile preview plays as loud as the slider (G-01-7). The user's decision changes from UAT are written into 01-CONTEXT.md so plans 01-09 and 01-10 build on recorded decisions.

const val FADE_FLOOR_DB = -45.0          // absolute dBFS where the final fade and the Stop ramp end, then mute
const val MIN_FADE_SPAN_DB = 10.0        // the final fade always spans at least this much
class SessionTimeline(startMs: Long, endMs: Long, fadeInMs: Long = 5_000, fadeOutMs: Long = 10_000,
                      rangeDb: Double = 60.0, floorDb: Double = FADE_FLOOR_DB, minSpanDb: Double = MIN_FADE_SPAN_DB) {
  fun endSpanDb(baseDb: Double): Double                       // finite base: max(base - floorDb, minSpanDb); otherwise minSpanDb

}
