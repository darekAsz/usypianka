## Phase Goal

**As a** parent, **I want to** choose a built-in noise, set a time and start playback, **so that** the sound fades in gently, loops without audible gaps (also with the screen locked) and fades to silence and stops when the time is up.

*(Story assembled from the ROADMAP Phase 1 Goal clauses — role "Rodzic", capability "wybiera wbudowany szum, ustawia czas i włącza odtwarzanie", outcome "łagodnie się pogłaśnia ... wygasza się do ciszy i zatrzymuje". The ROADMAP Goal line itself is not in user-story format and was not rewritten.)*

**This plan's slice:** the parent can install and open an app that is dark from the very first frame (UI-01 cold start). It also lays the toolchain every later slice compiles with.

<objective>
Bootstrap the Android toolchain on this Windows machine (SDK platform 37.0, Gradle 9.6.0 wrapper) and create the single-module Kotlin + Compose project exactly as verified in RESEARCH, ending with an installable app whose first frame is near-black.

Purpose: Everything in Phase 1 compiles against this build; the dark window theme is what prevents the white flash on cold start (UI-01, D-03).
Output: Gradle build files + wrapper, `.gitignore`, `app/build.gradle.kts`, manifest, dark theme, `MainActivity` with the `NightColors` scheme.
</objective>
