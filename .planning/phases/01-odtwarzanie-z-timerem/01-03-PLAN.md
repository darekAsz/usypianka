## Phase Goal

**As a** parent, **I want to** choose a built-in noise, set a time and start playback, **so that** the sound fades in gently, loops without audible gaps (also with the screen locked) and fades to silence and stops when the time is up.

*(Story assembled from the ROADMAP Phase 1 Goal clauses; the ROADMAP Goal line itself was not rewritten.)*

**This plan's slice (the phase TRACER / walking skeleton):** the parent taps Start and hears pink noise fade in, loop through the foreground service, show a countdown, and fade to silence at 0:00 — then the screen is idle again. Every layer the phase touches is wired here: asset -> ExoPlayer -> clock-driven engine -> MediaSessionService -> MediaController -> Compose screen.
